# Каталог учебных аудиторий

Программа для управления каталогом учебных аудиторий. Позволяет добавлять, удалять, просматривать и искать аудитории по различным параметрам. Данные хранятся в формате JSON.

## Запуск

Для запуска проекта из корневой папки используйте:

```bash
python -m catalog
```

Все команды выполняются через командную строку.

## Основные команды

По умолчанию программа работает в режиме read-only. Для выполнения операций изменения каталога необходимо использовать флаг `--admin`.

| Команда | Описание |
|---|---|
| `list` | Вывести все аудитории |
| `count` | Показать количество аудиторий |
| `iter` | Перебрать все аудитории |
| `get ID` | Получить аудиторию по ID |
| `contains ID` | Проверить наличие аудитории |
| `find category НАЗВАНИЕ` | Найти аудитории по категории |
| `find name НАЗВАНИЕ` | Найти аудитории по названию |

## Команды администратора

Для изменения каталога необходимо добавить флаг `--admin` перед названием команды.

**Добавление аудитории:**

```bash
python -m catalog --admin add "101" "Лекционная" 2024 50
```

**Удаление аудитории:**

```bash
python -m catalog --admin remove ID
```

**Импорт данных из JSON:**

```bash
python -m catalog --admin import tests/input.json
```

## Тестирование

Для запуска автоматических тестов используется `pytest`:

```bash
python -m pytest -v
```

## Структура проекта

```text
lab03/
├── catalog/
│   ├── __init__.py
│   ├── __main__.py
│   ├── errors.py
│   ├── models.py
│   └── storage.py
├── tests/
│   ├── input.json
│   ├── test_models.py
│   └── test_storage.py
├── catalog.json
└── .gitignore
```

Основная логика работы с аудиториями находится в `models.py`, операции чтения и сохранения данных — в `storage.py`, а обработка команд пользователя — в `__main__.py`.
